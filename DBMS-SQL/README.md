# DBMS-SQL

A structured collection of SQL queries, PL/SQL blocks, triggers, and mini-project database schemas.

## Repository Structure

- `SQL_Queries/` — standalone SQL problem solutions
- `PL_SQL_Blocks/` — PL/SQL blocks (CRUD, cursors, etc.)
- `Triggers/` — sample triggers for common constraints
- `MiniProjects/` — mini systems (schema + sample queries)

## Notes

- Most scripts assume generic table names such as `employees`, `students`, etc. Adjust table/column names to match your schema.
- `ER_Model.png` files in mini-project folders are placeholders; replace them with your actual ER diagrams.

## How to run

Open any `.sql` file in your SQL client (Oracle SQL Developer / SQL\*Plus / MySQL Workbench / SSMS) and execute after adapting table/column names.
